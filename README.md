# Schewels Home redesign concepts

Three clickable homepage concepts for Schewels Home, plus a pitch page with the audit of the current site.

- `index.html` – overview and audit, links to each concept
- `concept-a-heritage.html` – Since 1897: story and financing first
- `concept-b-rooms.html` – Room first: interactive room picker and payment estimator
- `concept-c-neighbor.html` – Find your Schewels: store finder as the hero

Plain HTML, no build step. Clone the repo and open `index.html` in a browser.

Unofficial concepts for review. Photos are Unsplash stand-ins, and the payment estimator is demo math only.
