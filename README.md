# Schewels Home redesign concepts

Three clickable homepage concepts for Schewels Home, plus a pitch page with the audit of the current site.

- `/` – overview and audit, links to each concept
- `/a/` – Since 1897: story and financing first
- `/b/` – Room first: interactive room picker and payment estimator
- `/c/` – Find your Schewels: store finder as the hero

Plain static HTML, no build step. Deploy the repo root as-is to any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages). All links are relative, so it also works under a sub-path like `/schewels-redesign-concepts/`. Pages are marked noindex.

Unofficial concepts for review. Photos are Unsplash stand-ins, and the payment estimator is demo math only.
